# 🔌 Integração WhatsApp - Opções Disponíveis

## 📚 **Bibliotecas Suportadas**

### 1️⃣ **@whiskeysockets/baileys** (Recomendado)
- ✅ Open-source e mantido
- ✅ Suporta WhatsApp Multi-Device
- ✅ Sem necessidade de servidor externo
- ✅ TypeScript nativo
- ⚠️ Requer gestão de sessões

**Instalação:**
```bash
npm install @whiskeysockets/baileys
npm install --save-dev @types/node
```

---

### 2️⃣ **Evolution API**
- ✅ API REST completa
- ✅ Multi-instâncias gerenciadas
- ✅ Webhooks integrados
- ✅ Dashboard web
- ⚠️ Requer servidor separado

**Setup:**
```bash
# Clonar Evolution API
git clone https://github.com/EvolutionAPI/evolution-api
cd evolution-api
docker-compose up -d
```

---

### 3️⃣ **Venom-bot**
- ✅ Fácil de usar
- ✅ Bem documentado
- ⚠️ Pode ter problemas de ban
- ⚠️ Menos mantido recentemente

**Instalação:**
```bash
npm install venom-bot
```

---

### 4️⃣ **WPPCONNECT**
- ✅ Baseado em Puppeteer
- ✅ Multi-sessões
- ⚠️ Mais pesado (Chrome headless)

**Instalação:**
```bash
npm install @wppconnect-team/wppconnect
```
